# HW-04: the GPIO output level is written before MODER, so the port drives PD1 from "not driven" straight to 1 where the
# original firmware first drives it to 0 (0x0801C08A) and then to 1 (0x0801C094).  The wake step "PD1 Z -> 1 with
# PE9=Z,PD1=Z" needs no entry: the original firmware makes it itself at wake (GPIO_Init at 0x0801BD86 with the PD1 output
# bit already set; whitelist 'power' line).  PE9 keeps the original order (src/brd/board.s: Z -> 0 with the port's MODER,
# PE12 low, then 0 -> 1 at the wake; no change at a cold start, where the bootloader has left it high), so it has no entry.
HW-04  safety_power  *  pins == PD1 and old == Z and new == 1 and ctx == PE9=1,PD1=Z
